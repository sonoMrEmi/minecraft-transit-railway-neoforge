# Minecraft Transit Railway (MTR)
### NeoForge Port [1.21.1]

An unofficial, high-performance port of the popular **Minecraft Transit Railway (MTR)** mod, built specifically for **NeoForge 1.21.1**.

This project brings the complete transit-building experience—automated trains, customizable dashboard systems, automated stations, and ticket mechanics—into the modern NeoForge ecosystem, ensuring seamless integration and optimal performance.

---

## Features

* **Full NeoForge Compatibility:** Native support for NeoForge 1.21.1, discarding legacy dependencies.
* **Feature Parity:** Includes all original train types, tracks, signposts, signaling systems, and custom display layouts.
* **Optimized Performance:** Reconfigured to maximize tick-rates and render pipelines alongside other modern NeoForge optimization mods.

---

## Requirements & Installation

To run this port, make sure you have installed the correct versions of the following dependencies:

1. **NeoForge:** Version `21.1.x` (or later recommended for 1.21.1).
2. **Architectury API:** Ensure you download the **NeoForge** specific build for `1.21.1`.

### Setup:
1. Download the latest `.jar` release from the releases section or Modrinth.
2. Place the file inside your server or client `mods/` directory.
3. Launch the game.
